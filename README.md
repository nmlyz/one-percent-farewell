A tiny program that writes one line — the last words a phone says as
its battery hits 1 percent — to a text file. The line is a single line
of at most 199 characters: the phone remembers dying at 20 percent
while its owner had a charger in their bag all along, and it says so
in three short beats.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (`OUTPUT_DIR` overrides the
directory). Running it twice produces byte-identical output.
